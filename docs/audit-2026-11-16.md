## 性能改进与实测

| 项目 | 修改前 | 修改后 | 说明 |
| --- | ---: | ---: | --- |
| 首屏入口 JS | 2,020.42 KB | 约 673 KB | 减少约 67%，终端和会话详情改为按需加载 |
| 300 个会话首次元数据扫描，中位数 | 349 ms | 168 ms | 耗时减少约 52% |
| 同一数据集缓存扫描，中位数 | 66 ms | 18 ms | 耗时减少约 73% |
| 一次文件变化通知对应扫描 | 主进程扫描后，渲染层再次要求扫描 | 渲染层直接取主进程已更新的快照 | 避免重复全量扫描；删除成功后也复用已刷新的索引 |
| Windows CLI PATH 查找 | 每次启动同步执行 4 次 where.exe | 直接检查 PATH 中的候选文件 | 保留原生 exe 优先选择，移除这部分子进程创建开销 |

扫描改进：每批最多并发处理 8 个会话；同一项目目录的存在性查询复用异步结果；附属目录通过一次目录枚举判断；复用已经取得的文件状态；移除重复目录读取。

基准使用本机临时目录：300 个 transcript，每个 100 条记录，共 30,000 条；每种扫描测量 3 次取中位数。“首次”指无本应用元数据缓存，不代表清空操作系统磁盘缓存。修改前首次扫描为 426/349/342 ms、缓存为 71/66/65 ms；修改后分别为 179/168/156 ms 和 18/16/18 ms。原始结果在 `.audit-backups/benchmark-before.json` 和 `benchmark-after.json`。

入口体积是生产构建输出的未压缩大小。详情约 923 KB、终端约 436 KB 在第一次使用时加载；本次主要减少启动所需代码，总代码及安装包体积不一定变小。未测量便携版自解压耗时、真实 CLI 启动耗时或端到端冷启动秒数。

## UI 改进

- 修复工作区 flex 容器不收缩导致的整页横向滚动和终端工具按钮溢出。
- 窗口缩小时自动调整实际面板宽度，为工作区保留 300px；放大后可恢复用户偏好的宽度。隔离实例在 960×600 外框、944px 内容宽度下验证无页面横向溢出。
- 分隔条支持方向键、Home、End，补充可访问性数值；拖动被取消或窗口失焦时恢复光标和选择状态。
- 对话框支持 Escape、焦点约束和关闭后焦点恢复；补充 dialog 语义。
- 手动浅色/深色主题同时控制代码高亮颜色，避免高亮仅跟随操作系统主题。
- 搜索框增加名称及 200 字符限制；修正托盘设置说明中的“开启/关闭”歧义。

## 后续仍有价值的改进

1. 大文件解析与全文搜索仍在主进程执行。解析大量 JSON 和工具输入时，建议迁移到 worker，并按文件版本建立可复用搜索索引；渲染层的大段 Markdown 高亮也可继续分摊。本次没有引入后台索引数据库。
2. 消息流默认显示最后 150 个事件，但命中较早消息时可能渲染从该位置到末尾的全部内容；会话列表和历史提示也未做虚拟滚动。超长会话可继续改成有界分页或虚拟列表。
3. Windows 结束终端仍调用同步 taskkill，单次超时上限 2 秒；同时结束多个会话时主进程可能短暂停顿。应另行实现异步停止及退出时的完整清理。
4. 历史删除增加了排队、备份和写入前复查，但仍是基于文件状态的乐观并发控制，没有跨进程文件锁；最后一次检查与 rename 之间依然存在小窗口，不能宣称对外部并发写入提供严格事务保证。
5. 本次没有验证真实 Claude 登录、网络请求、原生 IME、8 个真实 PTY 的长时间并发和安装器升级。1.0.13 打包内容与构建输出逐一核对，打包后的 Electron 与 node-pty 已通过一次实际 PTY 启动、输出和退出检查。现有 xterm 使用 beta 版本，后续升级时应单独回归中文输入法。
