# 文件粘贴与操作完整性核查

版本：1.1.2，提供便携版与安装版 EXE。旧版 1.1.1 EXE 不包含本次修改。

## 已修复

| 问题 | 当前行为 |
| --- | --- |
| 只识别剪贴板图片/文本，资源管理器复制文件无法添加 | 优先读取原生 `text/uri-list` 文件列表，验证后添加。复制图片文件保留原路径，纯截图仍保存 PNG。 |
| 附件直接写入终端，缺乏可靠撤销入口 | 增加待发送草稿：路径可编辑，附件可移除或清空，明确确认后发送或仅插入终端。 |
| 附件记录没有移除功能 | 增加逐个移除、清空记录；变更持久化，保留源文件和历史答复链接。 |
| 重复添加路径产生重复输入/引用标识变化 | 按规范路径去重，保留稳定附件标识。 |
| 写入终端失败被静默忽略 | 显示失败，保留草稿供检查与重试；发送前检查附件是否仍可访问。 |
| 关闭标签丢失未发送输入 | 附件草稿按会话保存在本地，重新打开恢复。 |
| 活动会话/收藏只能展开 | 再次点击切换收起与展开，保留当前会话记录。 |
| 收起历史记录后会话列表残留 | 收起时同步隐藏列表。 |
| 选择另一项目后新建对话可能使用旧标签目录 | 优先使用当前浏览的项目目录。 |
| 切换标签时拖放遮罩/菜单残留 | 非活动标签清理遮罩与菜单；恢复标签时优先聚焦草稿。 |
| 窄窗口标题被挤断，清空按钮在水平滚动末端 | 固定标题文字，清空按钮与可滚动附件列表分离。 |

移除引用不执行磁盘文件删除，也不会撤回已发送内容。附件记录隐藏后保留历史访问授权，避免旧答复的文件链接失效。截图保存在会话附件目录。

发送过程中终端写入失败时可能已写入部分内容；界面会提示先检查终端输入再重试，不自动重放。选择文件取消、文件不存在、附件清单不可写等情况会保留已有内容并给出相应反馈。

## 验证

- 100 项单元测试通过，1 项可选性能基准跳过；类型检查、生产构建通过。
- 40 项隔离 Electron 集成检查通过，渲染层控制台错误为零。
- 覆盖复制文件优先级、中文/空格、多路径、重复粘贴、原生文件拖放、截图草稿与发送、仅插入不提交、取消选择、移除失败重试、输入写入失败、草稿恢复、历史链接、列表收起和新建项目上下文。
- 没有修改系统剪贴板、删除用户文件或向真实 Claude 发送测试内容。测试使用临时会话、进程内剪贴板替身和终端 IPC 替身；保留真实 preload/webUtils、文件系统以及渲染 UI 链路。
- 报告：`.audit-backups/smoke-clipboard-removal.json`。修改前备份：`.audit-backups/before-clipboard-removal.zip`。

剪贴板适配依据：[Electron clipboard 官方文档](https://www.electronjs.org/docs/latest/api/clipboard)及其[原生文件列表读取实现](https://github.com/electron/electron/blob/main/shell/browser/api/electron_api_clipboard_item.cc)。
