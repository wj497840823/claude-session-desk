# 1.0.14：标签、删除与定位改进

- 移除后端 8 个运行中对话的固定上限。
- 标签栏新增管理菜单，标签右键也可操作：选择多个、关闭当前、其他、右侧、已结束及全部对话；Ctrl+点击支持多选。
- 批量关闭统一确认，异步等待进程结束后关闭标签。关闭失败时保留对应标签并提示；取消确认不会结束任何进程。
- 活动列表增加勾选、当前列表全选、批量删除和行尾删除。批量请求先校验全部会话，再结束关联进程，最后移入回收站并统一刷新。部分删除失败会报告结果并保留失败选择。
- 切换标签同步项目筛选、项目高亮、会话高亮及滚动位置，清除旧搜索以显示目标会话。关闭当前标签优先激活右侧相邻标签，否则选择左侧标签，并同步定位。
- 为新对话指定 UUID，通过 Claude CLI 的 `--session-id` 启动；首次记录被扫描后自动关联标签与会话。已产生记录的新对话重新启动时使用恢复参数。

验证：81 项单元测试、类型检查、生产构建通过。隔离 Electron 的 19 项集成场景通过，其中新增覆盖 12 个同时挂载的标签、跨项目锚点、关闭失败保留、批量取消与确认、右侧/其他关闭、新建 UUID 关联、活动列表批量与单条删除。终端启动/结束错误场景的主进程日志为测试预期输出。

集成测试使用假终端 IPC 与临时数据，不启动真实 Claude 对话，不对用户会话执行删除。打包后另已验证 12 个原生 PTY 的创建、输出与正常退出，并逐一核对主进程、预加载和全部前端资源与构建输出一致。
