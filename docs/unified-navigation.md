# 项目与会话合并导航

版本：1.1.1，提供便携版与安装版 EXE。旧版 dist/ClaudeSessionManager-1.1.0-*.exe 不包含本次导航调整。

## 修复的问题

旧的 setView 每次点击项目都会清空会话选择、详情和记录标签，即使选择仍在同一个项目中也会重置。旧排序会把收藏置顶，最近会话无法保持严格时间顺序。

## 行为

项目与会话使用同一个可调宽侧栏，项目支持独立展开/收起，展开后显示“最近”和按 updatedAt 倒序排列的会话；相同时间使用会话键稳定排序。项目展开状态保存在本地，切换终端标签时自动展开项目、恢复会话锚点并滚动到可见位置。

默认分批显示 20 条，可继续加载；被标签定位的较早会话自动包含在显示范围中。正常浏览释放原会话列给工作区，搜索时单独显示搜索结果列。活动会话、收藏、历史记录和右键删除继续可用。

重复点击项目只切换展开状态，保留选中的记录；切换导航范围时仅清除范围外的选择，并清空搜索。整个侧栏隐藏后，点击会话列表按钮可恢复侧栏。
