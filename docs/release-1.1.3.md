# 1.1.3 重新打包版：活动会话布局与文件链接修复

Windows x64：便携版 `dist/ClaudeSessionManager-1.1.3-portable.exe`，安装版 `dist/ClaudeSessionManager-1.1.3-setup.exe`。

本次保持 1.1.3 版本号，删除并替换旧的同名 EXE、blockmap 与校验文件，纳入文件链接识别和定位修复。

- 每次启动时活动会话默认收起，不沿用旧版的展开偏好。
- 点击展开后，会话列表紧接在“活动会话”下方、“收藏”上方；再次点击收起。
- 删除“最近”标题，保留按最后活动时间倒序排列、分批显示和标签定位。
- 包含 1.1.2 的文件复制粘贴、附件草稿、引用移除及失败恢复等功能。
- 文件链接显示前核验本机存在性，过滤无效路径及终端无效原生链接；短文件名和源码路径后缀只在项目内唯一匹配时定位。
- 修复 Java 行号范围、带空格的 Windows 路径和终端换行补白；蓝色语法配色保留，不等同于可点击文件。
- 修复异步布局后较早会话的滚动定位。
- 首次公开发布：补齐 MIT 与第三方依赖声明，并将其包含在应用包内。

源码验证：106 项单元测试、44 项隔离 Electron 集成检查通过，1 项可选性能基准跳过；类型检查与生产构建通过，另对截图实际项目做只读路径核验。

打包验证：核对包内版本及构建资源，检查 12 个原生终端的启动和退出。报告为 `.audit-backups/package-1.1.3.json`，校验值为 `dist/ClaudeSessionManager-1.1.3-SHA256.txt`。
