# 1.0.15：标签条空间与右键多选

修复 1.0.14 的布局回归：旧 `.terminal-tabs` 中的 `flex: 0 0 34px` 覆盖了 `.workspace-tabs` 的弹性宽度规则，导致水平布局中的标签容器只有 34px，右侧空间空闲而标签标题被裁切。

- 使用工作区限定的选择器设置弹性宽度，标签条占满扣除固定按钮后的剩余空间。
- 标签宽度 220px、标签条高度 46px、关闭按钮尺寸 24×24px；横向溢出只在标签条内部滚动。
- 按用户要求不增加独立多选操作栏。右键菜单提供选择当前标签、全选标签、关闭选中和取消多选；Ctrl+点击及标签复选框也可选中。
- 标签 tooltip 显示完整标题和项目路径。
- 活动会话列表去掉多选复选框、全选/删除选中栏和行尾删除按钮。右击目标会话选择「删除会话」，再确认移入回收站；取消或删除失败时保留会话。历史记录视图的既有操作保持原有行为。

验证：81 项单元测试、类型检查和生产构建通过；隔离 Electron 的 21 项集成检查通过。新增检查在单标签、12 个标签、多选模式及 960/1280/2560px 窗口中断言标签条填满可用空间、标题可读、按钮尺寸足够且整页无横向溢出，同时检查活动会话没有多选控件、右键删除只影响目标会话且支持取消和失败重试。新增断言在修改前成功复现了 34px 宽度问题。

测试驱动同时修正了失败退出码和临时 Chromium 配置目录清理：退出码在关闭窗口时保留，配置目录在子进程完全退出后由父进程清理，避免 Windows 文件锁影响结果。
