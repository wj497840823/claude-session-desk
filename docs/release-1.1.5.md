# 1.1.5：名称统一、状态通知与工作流增强

Windows x64：便携版 `dist/ClaudeSessionDesk-1.1.5-portable.exe`，安装版 `dist/ClaudeSessionDesk-1.1.5-setup.exe`。

- 用户可见名称统一为 **Claude Session Desk**：窗口标题、托盘、安装包、开始菜单、EXE 和发布名称一致；中文界面副标题为“会话工作台”。
- 内部 `appId` 与数据目录仍为 `claude-session-manager`，升级保留收藏、设置、缓存和附件记录。
- 安装版从 1.1.4 升级时安装目录和快捷方式名称会变化，建议先卸载旧版再安装；便携版直接使用新文件。
- 会话状态与桌面通知：工作中、等待确认、等待输入；窗口在后台时发送系统通知，点击回到对应对话。
- 用量与上下文：会话详情显示 token、缓存、估算成本和上下文占用；实时终端标签顶部也会显示当前模型和上下文占用，并展示最新 TodoWrite 任务清单。
- 标签恢复：重启后恢复上次打开的对话标签，由用户手动继续，不自动启动全部会话。
- 命令面板（Ctrl+Shift+P）和会话内查找（Ctrl+F）。
- 会话归档与侧栏“运行中”分组。
- 全局截图热键 Ctrl+Shift+5：截取鼠标所在屏幕并保存 PNG，路径直接插入当前对话。
- 修复首次展开项目时，持久化状态导致同时展开多个历史项目的问题；现在只展开当前项目。
- 会话右键和会话详情新增“复制并继续”：使用 Claude 原生 `--fork-session`，预分配新会话 ID 并保留原上下文，原会话不受影响。
- 任务栏角标显示待查看对话数量：会话完成或等待确认时计数，打开对应标签/记录后自动清除；托盘 tooltip 同步显示。
- 左侧内嵌会话列表增加最大高度并改为内部滚动，行高更紧凑，展开后不再占满整个侧栏。
- 左侧栏默认宽度由 320px 收窄到 296px，内嵌会话列表增加左右留白；旧的默认宽度会一次性迁移，手动调整过的其他宽度保持不变。

源码验证：155 项单元测试、54 项隔离 Electron 集成检查通过，1 项可选性能基准跳过；类型检查与生产构建通过。

打包验证：核对包内版本及构建资源，检查 12 个原生终端的启动和退出。报告为 `.audit-backups/package-1.1.5.json`，校验值为 `dist/ClaudeSessionDesk-1.1.5-SHA256.txt`。
