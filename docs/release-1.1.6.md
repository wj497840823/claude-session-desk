# 1.1.6：会话状态、待查看提示与终端交互修复

Windows x64：便携版 `dist/ClaudeSessionDesk-1.1.6-portable.exe`，安装版 `dist/ClaudeSessionDesk-1.1.6-setup.exe`。

- 空回车、方向键、展开/折叠思考内容不再被误判为提交了一轮对话。
- 一轮结束后，输入回显和终端重绘不再重复触发“完成”状态和待查看计数。
- 完成状态行（如 `✻ Sautéed for 6s · done`）不再被当作“工作中”。
- 空闲判定从 1.8 秒调整为 2.5 秒，减少思考或工具执行间隙的误判。
- 会话状态改由 Claude Code hook 驱动：`UserPromptSubmit` 进入“工作中”，`Stop` / `StopFailure` 才判定为“完成”，`PermissionRequest` 直接标记“待确认”，不再依赖静默计时或英文提示文本。
- 不支持 HTTP hook 的旧版本、未信任工作区或禁用 hook 的环境会自动回退到原有检测。
- 重启对话时清除上一轮的状态标记，避免启动后残留“完成”。
- 打开对应终端标签、会话记录页，或窗口重新聚焦时，会清除对应的待查看计数。
- 后台自动继续工作时，仍能通过明确的工作提示重新进入“工作中”。
- 终端标签保持单行：标题后以固定宽度显示项目名（柔和蓝灰色、字号略增、超出省略），状态使用单字母 W/A/D/R/S/E/U，完整含义在 tooltip；完成和待确认只用低饱和底色区分。
- 标签宽度缩短，减少横向占用；状态单字母和项目名共享固定空间。
- 标签左侧圆点改为“待查看”标记，只在未查看的完成/待确认会话上显示；已查看的会话不占用额外位置。
- 顶栏新增“待查看 N”：点击跳到待查看对话，点击 × 或侧栏“全部已读”可一次清除全部角标。
- 终端支持选中文本自动复制、右键粘贴；设置中可分别关闭，右键文件路径仍打开文件菜单。
- 包含 1.1.5 的全部功能与修复。

源码验证：161 项单元测试、55 项隔离 Electron 集成检查通过，1 项可选性能基准跳过；类型检查与生产构建通过。
