# 1.1.7：定时任务与 hooks 状态识别

Windows x64：便携版 `dist/ClaudeSessionDesk-1.1.7-portable.exe`，安装版 `dist/ClaudeSessionDesk-1.1.7-setup.exe`。

- 左侧栏新增“定时任务”：支持 Claude 提示词任务和项目命令/脚本。
- 调度支持仅一次、每天、每周、每隔 N 分钟/小时；可启用/暂停、立即运行、编辑、删除和查看日志。
- 明确区分“定时启用”和“立即运行一次”；运行中显示停止按钮，可手动终止，运行记录标记为“已取消”。
- 运行中的任务可直接删除：会先停止当前运行再删除，避免任务卡在“运行中”无法操作。
- Claude 定时任务默认使用只读/计划模式，以非交互方式运行并生成正常会话记录；命令任务以当前用户权限在项目目录执行。
- Claude 任务支持“每次新建会话”“复用专用会话”“选择已有会话”：选择已有会话时可按项目挑选目标会话，之后每次运行都把提示词追加到该会话。
- 运行期间会锁定目标会话，避免同一会话被同时在标签页打开；选择已有会话时会校验 transcript 来源与项目目录是否存在。
- 运行结束后先写入运行记录并清理超出的日志，再报告任务结束，避免“已结束”状态下记录或日志尚未落盘。
- 成功/失败/取消发送桌面通知，并遵循“桌面通知”设置；日志写入失败不会让任务卡在运行状态。
- 同一任务不会并发运行，默认 30 分钟超时，保留最近 20 次运行日志。
- 定时任务需要应用保持运行（可隐藏到托盘）；完全退出后不会执行。
- 会话状态优先使用 Claude Code hooks（UserPromptSubmit / Stop / StopFailure / PermissionRequest / PermissionDenied），通过本机回环 HTTP 中继更新“工作中 / 完成 / 待确认”。
- hooks 仅在收到明确状态事件后接管，未知/异常事件不会关闭回退；Esc 与 Alt 组合键区分，避免误判中断。
- 修复审批框中 Esc/Ctrl+C 的状态处理，以及工作期间预输入内容在完成判定后的保留。
- 修复 hook 中继启动后服务器错误可能变成主进程未捕获异常的问题。
- 修复路径包含关系判断对以 `..` 开头的合法目录名的误判。
- hooks 不可用时回退到终端输出启发式；本地 hook 流量加入 NO_PROXY。
- 包含 1.1.6 的状态修复、单行标签、待查看角标、选中复制和右键粘贴等功能。

源码验证：211 项单元测试、57 项隔离 Electron 集成检查通过，1 项可选性能基准跳过；类型检查与生产构建通过。
