# 文件链接误识别与短路径定位

发布：包含在重新打包的 1.1.3 便携版与安装版中，旧的同名发布文件已移除。版本号保持 1.1.3，以新的 SHA256 校验值区分。

## 定位

原逻辑根据扩展名、斜杠等文本特征直接生成链接，显示前没有检查文件是否存在。短文件名仅拼接会话 cwd，没有查找模块源码子目录；Java 行号范围在路径解析阶段也可能被误判为 URI 协议。终端换行时读取空白单元格会把补白拼入路径。

截图中的蓝色同时包含 Claude 终端原有的代码语法配色，不能用颜色判断文件。方法调用、字段名、示例 token 和服务器 Linux 路径都不能直接作为本机文件打开。

例如 `ExceptionAdvice.java:73` 和 `StorageEngine.java:62-66` 可能实际位于多层源码目录，项目根目录下不存在这些文件。此时应解析到项目内唯一的真实路径。如果 `DownloadService.java` 在多个模块中重名，短名称不做猜测，使用对应完整路径定位。这里的文件名为匿名化示例。

## 当前行为

- Markdown、普通文本和实时终端推断链接均先批量核验本机文件，未核验成功的内容保留为文本，不触发打开。
- 终端原生 OSC 8 本地链接也进行校验；真实文件保留点击能力，未知协议及无效文件链接被过滤。网页链接继续正常打开。
- 短文件名或源码后缀仅在项目内有唯一匹配时解析。项目索引跳过依赖、版本控制目录与符号链接目录；遍历有数量、深度、时间和缓存限制。扫描不完整或重名时要求完整路径。
- 支持 Java 行号范围、中文、带空格的 Windows 路径、Git Bash 盘符路径；普通文件 URL 锚点不会被拼成文件名。保留项目边界、附件授权与符号链接越界检查。
- 终端路径识别排除行末补白；内容在异步核验期间变化或组件已销毁时丢弃过期结果。
- 活动会话滚动定位使用侧栏自身坐标，并在布局尺寸变化时保持选中行可见。

文件操作仍以打开或资源管理器定位为主，行号用于识别文件，不提供编辑器精确跳行。蓝色语法配色本身不改变。
