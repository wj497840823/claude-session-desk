# 1.1.0：附件、文件链接与任务栏行为

状态：源码实现与自动化验证已完成，随后按用户要求生成 1.1.0 便携版与安装版 EXE。1.0.15 可执行文件不包含本次修改。

## 使用

1. 在运行中的 Claude 对话按 Ctrl+V 粘贴截图/图片，或点击右上角粘贴按钮。没有图片时继续粘贴普通文本。
2. 点击回形针选择本地文件或图片，也可拖放本地文件到当前对话。多个路径使用引号分隔，插入输入后由用户自行发送，不注入 Enter。
3. 已引用的附件显示在终端上方；图片提供可用的缩略图。点击文件名打开，右键可定位和复制路径。
4. 实时终端、Markdown 会话答复和工具调用中的文件路径可打开。Shift+点击定位，右键提供打开、在文件夹中定位和复制路径。
5. 最小化采用系统默认行为，保留任务栏图标；关闭到托盘继续由原设置控制，设置文案同步改为“关闭窗口时隐藏到托盘”。

## 实现与边界

- 使用当前 Electron 的异步剪贴板 API、原生文件选择器和 preload `webUtils.getPathForFile`，兼容启用隔离与沙箱的渲染进程。
- 截图保存到用户数据目录 `attachments/<会话 UUID>/`，附件清单以原子替换和会话写入队列保存；选择/拖入的已有文件按实际路径引用，不移动原文件。
- 附件在输入阶段仅插入带引号的本地路径，后续读取与模型处理由 Claude Code 执行。可解析的文档类型仍取决于 CLI 的工具环境。
- 默认限制每次最多 16 个文件、单张图片 25 MB，剪贴板图片另限制像素量；文本粘贴不经过附件路径转换。
- 文件操作根据真实会话的目录、该会话明确添加的文件和 Claude 数据目录进行验证，兼顾路径规范化、符号链接越界、URI 编码、中文、空格与行号后缀。
- 终端链接提供器根据实际单元格宽度定位 CJK 字符，并拼接有限数量的换行行。Markdown 文件链接、行内路径和工具调用结构化路径也提供相同操作。
- 程序和脚本文件会在文件管理器中定位，避免把点击文件链接变成自动执行程序；HTTP/HTTPS 链接继续交给默认浏览器。
- 磁盘文件不存在或已移动时提示；不会将模型提到的文件名当作“文件已经生成”的证明。行号后缀用于识别文件，本版不提供编辑器精确跳行。

## 验证

最终结果：90 项单元测试通过，1 项可选性能基准默认跳过；类型检查与生产构建通过，28 项隔离 Electron 集成检查通过，渲染层控制台错误为零。

新增单元测试覆盖路径解析、中文与空格、协议/控制字符拒绝、附件引用转义、项目文件打开、附件授权持久化、并发清单保存、符号链接越界、目录与超量附件拒绝、普通文本粘贴、图片大小限制和工具输入截断后的文件信息保留。

隔离 Electron 集成测试覆盖 Ctrl+V 图片保存及无自动发送、纯文本回退、原生选择器、真实磁盘 File 经过拖放与 preload 桥接、中文终端文件链接、跨行且含空格的完整路径、Markdown 打开和右键定位，以及原有标签/删除/布局场景。测试不修改系统剪贴板，不打开真实外部程序，不向 Claude 发送消息。
