# Claude Session Desk 1.3.0

## 新增

- 权限审批闭环：会话等待确认时，可在「待处理」面板直接允许或拒绝操作，结果通过 Claude Code `PermissionRequest` hook 回写，不再必须切回终端。
- 定时运行的 Claude 任务同样注入 hook 中继：遇到需要权限的操作会进入待处理，允许后继续本轮，超时则退回 Claude 原生询问。
- 结构化提问：定时任务可以在最后一条回复附带 `claudeview` 提问块；应用在「待处理」展示选项和输入框，回答后用 `--resume` 接回原会话继续，等待期间不占进程、不消耗 Token。
- 统一「待处理」收件箱：聚合权限请求、任务提问与定时任务最新结果，支持查看输出摘要、标为已读、立即重试和跳转会话。
- 可选本地 HTTP 接口：查询状态/任务/收件箱/用量，运行、暂停、恢复、补跑任务，回答审批与提问，提交外部事件；只监听 `127.0.0.1`，使用 Bearer Token，默认关闭。详见 [本地 HTTP 接口](local-api.md)。
- 外部事件触发：任务可配置事件类型（精确或 `prefix.*`）；事件正文写入本地资料文件，提示词只包含类型、对象和资料路径，事件不能指定目录、Agent 或权限。
- 定时任务失败重试：按 5 分钟、10 分钟、20 分钟……退避，最长 60 分钟；连续失败 10 次后停止。第 3 次失败起在通知中提示检查任务配置。
- 续接/新开语义：失败前没有产生模型输出时，重试使用新会话；已经开始的失败续接原会话，避免重做已完成的副作用。手动运行会取消待重试并从第 1 次重新开始。
- 用量上限感知：识别 Claude 的 `usage_limit_reached` 与恢复时间，排队定时任务、只通知一次，恢复后自动继续；手动运行不受限。
- 文件/Git 触发器：定时任务可附加监视文件或文件夹变更，或项目 Git 新提交；文件变更带 2 秒防抖，同一任务 5 分钟内最多触发一次。
- 暂停与补跑：任务可暂停 1 小时或恢复；暂停期间被跳过的触发会记录次数，恢复后可一键补跑。
- 用量看板：定时任务对话框新增「用量」页，显示今天/近 7 天的 token、缓存、估算费用与按任务明细，并单列缺少用量和未定价的运行。
- 项目 CLAUDE.md 编辑支持选择位置：项目根目录 `CLAUDE.md` 或 `.claude/CLAUDE.md`；打开时优先加载已有文件，两处同时存在时提示只保留一处。
- 会话结束但仍有后台任务时显示“后台任务中”，不再误报“等待输入 / 已完成”；依据 `Stop` hook 的 `background_tasks` 与 `session_crons` 判断，后台任务结束后自动回到空闲。

## 实现说明

- 交互会话通过本机回环 HTTP 中继接收 hook；审批请求默认等待 4 分钟，超时或窗口关闭时返回空决策，退回终端原生权限询问。
- 定时 Claude 任务改用 `stream-json --verbose` 运行，`ClaudeStreamLog` 将 JSONL 还原为可读日志，同时采集会话、token、模型和限额恢复时间。
- 用量费用按内置价目表估算；第三方或未知模型显示「未定价」，token 仍正常统计。
- 用量统计仅覆盖定时 Claude 任务，且每个任务只保留最近 20 次运行；历史会话用量仍见会话详情。
- 文件触发监视指定路径（目录为非递归）；Git 触发每 15 秒轮询 `git rev-parse HEAD`。项目不是 Git 仓库或未安装 Git 时不会触发。
- 用量限制状态保存在内存，应用重启后会重新探测。

## 兼容性

- 内部应用标识与数据目录仍为 `claude-session-manager`；升级不会丢失收藏、设置、定时任务、跳过记录或附件记录。
- 旧的定时任务和运行记录可直接读取；新增的重试、触发器、暂停、用量字段均为可选字段。
- 定时 Claude 任务需要支持 `--output-format stream-json --verbose` 的 Claude Code 版本（当前验证版本 2.1.318）。
