# Claude Session Desk 1.2.0

## 新增

- 内置 9 个 CLAUDE.md 模板：3 个全局模板（精简、标准、严格）和 6 个项目模板（最小改动、标准开发、严格变更、代码审查、测试优先、自主执行）。
- 设置对话框新增「CLAUDE.md 全局规则」区块：选择全局模板后可以全量替换或增量添加到 `~/.claude/CLAUDE.md`，也可以打开应用内编辑器直接修改。
- 项目右键菜单新增「编辑 CLAUDE.md」：编辑项目根目录的 `CLAUDE.md`，支持相同的模板、全量替换和增量添加能力。
- 完整模板管理：内置模板只读，可复制为自定义模板；自定义模板支持新建、编辑、删除、导入 `.md` 文件，并按全局/项目作用域分类。
- 每次覆盖已有文件前自动生成 `CLAUDE.md.bak-YYYYMMDD-HHmmss` 备份；备份失败时中止写入，保留原文件。
- 项目栏新增 Git 变更徽章：显示唯一变更文件数，并按冲突 / 已跟踪变更 / 仅未跟踪着色。
- 新增 Git 变更面板：查看分支、上游 ahead/behind、冲突 / 已暂存 / 未暂存 / 未跟踪四组文件，并按需加载 unified diff。
- 支持单个或全部暂存/取消暂存、提交已暂存内容；冲突文件可通过暂存标记为已解决。

## Git 变更面板

- 徽章每 30 秒刷新一次；面板打开时每 5 秒刷新当前项目。
- 读取使用 `git status --porcelain=v2 --branch -z` 与 `git diff --numstat -z`；路径统一按项目相对显示。
- 提交默认执行 Git 钩子；面板提供“跳过 Git 钩子”选项（`--no-verify`），钩子失败时展示原始输出并中止提交。
- 暂存与取消暂存按整文件操作，不提供 hunk 级暂存；不提供丢弃、回滚、拉取或推送。
- 项目不是 Git 仓库时不显示徽章，面板会提示原因；未安装 Git 时同样给出明确提示。
- 项目位于 monorepo 子目录时，只统计该项目子树，不会把仓库其他目录的变更计入徽章。
- 只读命令禁用 `core.fsmonitor`、external diff 与 textconv；所有命令通过参数数组调用，不经过 shell。

## 行为说明

- “增量添加”按标题去重：去掉标题前的编号并忽略大小写和多余空白，同名小节不会重复追加；代码围栏内的 `#` 不会被当作标题。
- 目标文件不存在时，保存或应用模板会自动创建 `~/.claude` 目录或项目根目录下的 `CLAUDE.md`。
- 模板内容限制为 1 MiB，模板名 1–60 字，说明不超过 200 字，自定义模板最多 200 个。
- 自定义模板保存在应用数据目录的 `claude-md-templates.json`，不会写入项目仓库；损坏的模板库会在下次写入前重命名保留。
- 读取和写入会去除 UTF-8 BOM；包含 NUL 等二进制字符的内容会被拒绝。
